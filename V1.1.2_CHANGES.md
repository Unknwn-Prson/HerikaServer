## Summary

---

## Fix #1: Duplicate Memory Removal Timing (Issue #2)

### Problem

`removeDuplicateMemories()` was called AFTER cache markers were placed. When duplicate memories were removed:
- Array size changed
- Indices shifted
- Cache markers moved to wrong messages or were removed entirely
- Caused unpredictable cache behavior

### Solution

Moved `removeDuplicateMemories()` to run BEFORE cache calculations:

**Files Modified**:
- `connector/openrouterjsoncached.php` line ~506
- `connector/openrouterjsoncached_verbose.php` line ~663

**Change**:
```php
// OLD LOCATION (line 585/899): After cache placement
$completeEventList = removeDuplicateMemories($completeEventList);  // TOO LATE

// NEW LOCATION (line 506/663): Before cache calculation
$completeEventList = removeDuplicateMemories($completeEventList);  // CORRECT
```

**Benefits**:
- Cache markers now placed on correct messages
- Array size stable during cache calculations
- Duplicate memories removed before they affect indexing
- Added logging to track deduplication count

## Fix #2: Missing TEMPLATE_DIALOG Prompt

### Problem

The dialogue template prompt (`"Write HERIKA_NAME's next dialogue line"`) was completely missing from openrouterjsoncached connector. This prompt:
- Tells the LLM how to roleplay/respond
- Is controlled by `minimize_quality_prompt` setting
- Should be in uncached section (not system prompt)
- Was present in CHIM 1.3.5 but lost in openrouterjsoncached

### Solution

Added `TEMPLATE_DIALOG` insertion after last user message:

**Files Modified**:
- `connector/openrouterjsoncached.php` line ~524
- `connector/openrouterjsoncached_verbose.php` line ~703

**Implementation**:
```php
// Add after instruction (last user message)
if (isset($GLOBALS["TEMPLATE_DIALOG"]) && !empty($GLOBALS["TEMPLATE_DIALOG"])) {
    $addToIndex++;
    $completeEventList[] = ['type' => 'text', 'text' => $GLOBALS["TEMPLATE_DIALOG"]];
    logMessage("Added TEMPLATE_DIALOG to uncached section...");
}
```

**What It Does**:
- Reads `$GLOBALS["TEMPLATE_DIALOG"]` set by `prompts/dialogue_prompt.php`
- Inserts in uncached section (changes per turn)
- Respects `minimize_quality_prompt` setting:
  - **Enabled** (minimized): "Write {NAME}'s next dialogue line."
  - **Disabled** (verbose): Full instruction with quality guidelines

**Message Sequence Now**:
```
1. System prompt with format instructions (CACHED)
2. Dialogue history (CACHED)
3. Dynamic environment (UNCACHED)
4. Custom last instruction (UNCACHED, if enabled)
5. Last user message (UNCACHED)
6. TEMPLATE_DIALOG (UNCACHED) ← NEW
```

**Benefits**:
- LLM now receives roleplay instruction
- Users can toggle verbose/minimized via `minimize_quality_prompt`
- Matches CHIM 1.3.5 behavior
- Instruction in uncached zone (proper placement)
