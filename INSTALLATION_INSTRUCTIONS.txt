CHIM CACHED CONNECTOR v1.0.16 - INSTALLATION INSTRUCTIONS
===============================================================================

IMPORTANT: Version 1.0.16 includes increased parameter precision (4 decimals
instead of 2) to allow values like 0.1234 for temperature and other LLM
parameters.

===============================================================================
INSTALLATION STEPS
===============================================================================

1. BACKUP YOUR EXISTING FILES FIRST
   Before installing, backup these files if they exist:
   - HerikaServer/connector/openrouterjsoncached.php
   - HerikaServer/connector/openrouterjsoncached_verbose.php
   - HerikaServer/connector/openrouterjsoncached_helpers.php
   - HerikaServer/ui/core/llm_connectors.php

2. EXTRACT AND COPY FILES
   Copy the files from this zip to your HerikaServer directory, maintaining
   the directory structure:

   connector/openrouterjsoncached.php                → HerikaServer/connector/
   connector/openrouterjsoncached_verbose.php        → HerikaServer/connector/
   connector/openrouterjsoncached_helpers.php        → HerikaServer/connector/
   ui/core/llm_connectors.php                        → HerikaServer/ui/core/
   ui/core/_par_precision_llm_connectors.php         → HerikaServer/ui/core/

3. DELETE THE BACKUP FILE (BEFORE PRODUCTION)
   The file _par_precision_llm_connectors.php is a backup for reference only.
   - Keep it during development/testing
   - DELETE it before deploying to production
   - Do NOT let Claude (AI) delete it - only humans should

4. CLEAR BROWSER CACHE
   After copying files, you MUST clear your browser cache:
   - Chrome/Edge: Ctrl + Shift + Delete → Clear cached images and files
   - Firefox: Ctrl + Shift + Delete → Cache
   - Or do a hard refresh: Ctrl + F5 (Windows) or Cmd + Shift + R (Mac)

5. VERIFY INSTALLATION
   - Open HerikaServer web interface
   - Go to LLM Connectors configuration page
   - Try entering a value like 0.1234 in temperature field
   - Should now accept up to 4 decimal places without "please enter a valid
     value" error

WHAT'S NEW IN v1.0.16
===============================================================================

✓ Increased LLM parameter decimal precision from 2 to 4 decimals
  - OLD: Could only enter 0.12 (limited to 2 decimal places)
  - NEW: Can enter 0.1234 (up to 4 decimal places)

✓ Affects these parameters:
  - temperature
  - presence_penalty
  - frequency_penalty
  - repetition_penalty
  - top_p
  - min_p
  - top_a

✓ Resolves "please enter a valid value" validation errors

===============================================================================
TROUBLESHOOTING
===============================================================================

Issue: Still getting "please enter a valid value" error
Solution:
  1. Verify you copied ui/core/llm_connectors.php to the correct location
  2. Clear browser cache completely (Ctrl + Shift + Delete)
  3. Do a hard refresh (Ctrl + F5)
  4. Check file permissions (should be readable by web server)
  5. Verify you're editing the LLM Connector (not Profile settings)

Issue: Changes don't appear in UI
Solution:
  1. Hard refresh browser (Ctrl + F5)
  2. Clear all browser cache
  3. Restart web server if needed
  4. Check file timestamps to confirm new files are in place

Issue: Connector doesn't work
Solution:
  1. Verify all three connector files were copied
  2. Check PHP error logs
  3. Ensure helpers file is present
  4. Try the verbose connector for detailed logging
