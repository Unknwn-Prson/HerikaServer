## Installation Steps

### 1. Backup Current Files (IMPORTANT!)

Backup these files before installing:
```
connector/openrouterjson*.php (if using cached connector)
ui/core/llm_connectors.php
ui/core/core_profiles.php
conf/conf_schema.json
```

### 2. Extract Files

Extract all files from the zip, maintaining the directory structure:
```
HerikaServer/
├── connector/
│   ├── openrouterjsoncached.php (v1.1.5)
│   ├── openrouterjsoncached_helpers.php
│   └── openrouterjsoncached_verbose.php (v1.1.5)
├── ui/core/
│   ├── llm_connectors.php
│   └── core_profiles.php
├── conf/conf_schema.json
├── lib/
│   ├── core/llm_connector.class.php
│   ├── chat_helper_functions.php
│   ├── data_functions.php
│   └── tokenizer_helper_functions.php
├── functions/json_response.php
├── ui/events-memories.php
└── prompts/dialogue_prompt.php
```

### 3. Verify Installation

Check that version is correct:
- Look in connector file header for: `v1.1.5 for CHIM 2.0.3 | 2025/11/12`

### 4. Configure Connector

In CHIM WebUI:
1. Go to **Profiles** or **LLM Connectors**
2. Select or create connector with driver: `openrouterjsoncached`
3. Configure settings:
   - **Provider Caching**: Anthropic, OpenAI, or Gemini
   - **Response Format**: JSON or Simple (both work now!)
   - **Uncached Count**: 4 (recommended)
   - **Minimize Quality Instructions**: Enabled for advanced models

### 5. Test Configuration

Run a conversation and verify:
- Full messages appear (no missing first character)
- Profile section settings save correctly
- Simple format works (if enabled)

## Configuration Options

### Caching Settings
- **Provider Caching Type**: Anthropic, OpenAI, or Gemini
- **Uncached Dialogue Count**: Recent messages kept uncached (default: 4)
- **Minimize Quality Instructions**: Short vs verbose dialogue instruction

### Response Format (Collapsible)
- **Response Format**: JSON (structured) or Simple (natural with markers)
- **Include Mood**: Toggle mood requirement
- **Include Listener**: Toggle listener specification
- **Include Actions**: Toggle action selection
- **Include Target**: Toggle action target

### Advanced Settings (Collapsible)
- **Max Dialogue Cache**: Maximum cached messages (default: 93, max: 2000)
- **Custom System Instruction**: Additional system prompt
- **Custom Last Instruction**: Instruction added near end
