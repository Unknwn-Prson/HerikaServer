CHIM Cached Connector v1.2.1 - Release Notes
============================================
Release Date: 2025-11-15
Compatible with: CHIM 2.0.3

OVERVIEW
--------
v1.2.1 is a COMPLETE REBUILD from v1.0.12 baseline, incorporating all working
features from v1.1.22 while maintaining the WORKING thinking toggle implementation.

This release represents 8+ hours of debugging and systematic rebuilding to resolve
the thinking toggle save bug that plagued v1.1.22 through v1.1.32.

MAJOR CHANGES FROM v1.0.12
---------------------------

1. WORKING SIMPLE FORMAT IMPLEMENTATION
   - Complete rewrite of natural language response parsing
   - State machine for proper stream processing
   - Support for response_format metadata field (json/simple)
   - Simple format content options:
     * include_mood_requirement
     * include_listener_requirement
     * include_actions_list
     * include_target_requirement
   - Intelligent prefill handling (disabled when reasoning is active)

2. THINKING TOGGLE - FULLY FUNCTIONAL
   - Works with BOTH JSON and simple formats
   - Properly saves and loads settings
   - Correctly enables reasoning in API payloads
   - Fixed incompatibility between prefill and reasoning
   - Supports all reasoning parameters:
     * toggle_thinking (boolean)
     * thinking_tokens (number)
     * effort_level (minimal/low/medium/high)

3. NEW CONFIGURATION FIELDS
   - max_dialogue_cache_context_size (default: 93)
   - custom_system_instruction (textarea)
   - custom_last_instruction (textarea)
   - minimize_quality_prompt (checkbox, default: ON)

4. IMPROVED PRECISION
   - Updated decimal precision from 2 to 4 decimals
   - Affects: temperature, presence_penalty, frequency_penalty,
            repetition_penalty, top_p, min_p, top_a
   - Better fine-tuning control for parameters

5. CACHING IMPROVEMENTS
   - Provider caching type selector (Anthropic/OpenAI/Gemini)
   - Response format selector (JSON/Simple)
   - Uncached dialogue count configuration
   - Verbose logging option for testing

CRITICAL BUG FIXES
------------------

BUG #1: Thinking Toggle Not Saving
   - ROOT CAUSE: Duplicate name attributes on form fields caused conflicts
   - RESOLUTION: Maintained proper name='metadata[field]' pattern from v1.0.12
   - STATUS: FIXED - Settings now save and load correctly

BUG #2: Thinking Not Working with Simple Format
   - ROOT CAUSE: Prefill and reasoning are mutually incompatible
   - RESOLUTION: Skip prefill when thinking is enabled
   - STATUS: FIXED - Reasoning now works with both formats

BUG #3: Simple Format Not Functioning
   - ROOT CAUSE: Broken parser implementation in v1.0.12
   - RESOLUTION: Replaced with v1.1.20 working implementation
   - STATUS: FIXED - Simple format fully functional
